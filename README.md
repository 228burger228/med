# 🩺 Ainala Rehab — Платформа безопасной реабилитации (MVP 0.2)

> **Демо (GitHub Pages):** [https://228burger228.github.io/med/](https://228burger228.github.io/med/)  
> **Репозиторий:** [https://github.com/228burger228/med](https://github.com/228burger228/med)

Интерактивное веб/мобильное приложение, которое помогает пациентам безопасно проходить реабилитацию после травм и операций, контролировать боль и амплитуду движений (ROM), рассчитывать нормы восстановления и делиться клиническими отчётами с лечащим врачом.

---

## 🚀 Быстрый старт для разработчика

### 1. Локальная разработка (Vite Dev Server)
```bash
npm install
npm run dev
```
Откроется локальный сервер с Hot Reload: `http://localhost:5173/`

> **Важная деталь по `index.html`:**  
> Чтобы приложение работало на GitHub Pages напрямую из ветки `main` и открывалось двойным кликом без сервера, в корне лежит скомпилированный автономный `index.html`.  
> При запуске `node build-standalone.js` скрипт автоматически восстанавливает шаблон Vite, собирает свежий бандл из `src/` и пакует его в корневой `index.html`, `dist/index.html` и `docs/index.html`.

### 2. Сборка и деплой на GitHub Pages
```bash
node build-standalone.js
git add .
git commit -m "chore: rebuild standalone bundle"
git push origin main
git push origin main:gh-pages --force
```

## ✅ Что уже сделано (Статус MVP 0.2)

### 1. Исправленные баги первоначального прототипа
- **Кольцо таймера (`RecoveryRing`)**: устранён баг наложения текста `{percent}% СЕГОДНЯ` и обратного отсчёта секунд в режиме тренировки.
- **Адаптивность тегов (`Pill`)**: исправлен разрыв плашек (`Колено · ранняя фаза`) на мобильных экранах (`inline-flex`, `white-space: nowrap`).
- **Устранена критическая уязвимость с AI API**: в исходном прототипе был прямой `fetch("https://api.anthropic.com/v1/messages")` из клиентского кода (риск утечки API-ключа и блокировка CORS). Вызовы вынесены в сервисный слой `src/services/aiService.js` с поддержкой бэкенд-прокси (`VITE_API_PROXY_URL`) и офлайн клиническим NLP-движком.
- **Сохранение состояния (`localStorage`)**: профиль травмы, статус входа, задачи на день и статус подписки сохраняются между перезагрузками страницы.

### 2. Реализованные продуктовые модули
- **⚡ Панель экспресс-скрининга (`ExpressDemoBar`)**: верхний HUD-бар для быстрой демонстрации заказчику — переключение суставов (`Колено`, `Плечо`, `Спина`, `Перелом руки`, `Голеностоп`) в 1 клик, переключатель `PRO ВКЛ/ВЫКЛ`, быстрый переход к калькуляторам и сброс анкеты.
- **🧮 3 математических калькулятора реабилитации (`src/components/CalculatorsAndVideoHub.jsx`)**:
  1. *Калькулятор сроков и фаз*: рассчитывает реалистичный коридор восстановления (быт / работа / спорт) с учётом сустава, возраста и прошедших недель.
  2. *Калькулятор нутриентов и гидратации*: считает норму белка ($1.5\text{–}1.8\text{ г/кг}$), чистой воды ($32\text{ мл/кг}$) и протокол приёма коллагена + витамина C за 45 минут до ЛФК.
  3. *Калькулятор прогрессии нагрузки («Светофор боли»)*: по боли на тренировке и утренней реакции сустава выдаёт зелёный (`+10–15%`), жёлтый или красный коридор (`-50%` нагрузки).
- **🎬 Встроенная Видео-база (`VideoHubModal`) + Тренировка (`GuidedSession`)**:
  - Фильтрация упражнений по всем категориям травм.
  - Интерактивная биомеханическая SVG-анимация движения сустава.
  - Синхронизированные субтитры `[CC]` по таймкодам и процедурная озвучка таймера на **Web Audio API** (`src/utils/sound.js` — без внешних MP3-файлов).
- **🚨 Экстренная памятка «Красные флаги» (`RedFlagsModal` + кнопка `SOS`)**:
  - Чек-лист критических симптомов (признаки ТГВ/тромбоза, ТЭЛА, инфекции шва, неврологического дефицита) с кнопкой вызова `112 / 103`.
  - Автоматический перехватчик опасных симптомов (`detectRedFlagsInText` в `src/utils/security.js`) при вводе в анкете и ИИ-чате.
- **🩺 Раздел «Врач и отчёт»**:
  - Генерация структурированной сводки за 7 дней: копирование в 1 клик для отправки врачу в Telegram + экспорт на печать / PDF.
- **📸 Трекер прогресса, дневник симптомов и фото «До / После»**:
  - График боли и подвижности (`recharts`), чек-лист сна и питания, локальное сравнение фотографий «До / После» (без загрузки сырых фото в сторонние облака без согласия).
- **🗄 Готовая схема БД (`supabase-schema.sql`)**:
  - Таблицы `patient_profiles`, `symptom_logs`, `exercise_sessions`, `community_posts` с настроенными политиками **Row Level Security (RLS)**.

## 📂 Архитектура проекта

```text
ainala-rehab/
├── src/
│   ├── components/
│   │   ├── ui/SharedUI.jsx            # Базовые UI-компоненты, модалки <dialog>, плеер
│   │   └── CalculatorsAndVideoHub.jsx # 3 калькулятора, VideoHubModal, ExpressDemoBar, PhotoTracker
│   ├── data/
│   │   └── mockData.js                # Клиническая база ЛФК, таймкоды субтитров [CC], статьи, Red Flags
│   ├── services/
│   │   └── aiService.js               # Безопасный клиент для AI-прокси + локальный медицинский классификатор
│   ├── theme/
│   │   └── tokens.js                  # Дизайн-токены (палитра Ainala, типографика Inter / Fraunces / Mono)
│   ├── utils/
│   │   ├── security.js                # Санитизация XSS, детектор «красных флагов», экспорт GDPR/152-ФЗ
│   │   └── sound.js                   # Процедурные звуки таймера на Web Audio API
│   ├── App.jsx                        # Корневой компонент и экраны приложения
│   ├── index.css                      # Глобальные стили, анимации и переходы
│   └── main.jsx                       # Точка входа React
├── supabase-schema.sql                # SQL-схема для Supabase (PostgreSQL + RLS)
├── build-standalone.js                # Скрипт сборки автономного бандла для GitHub Pages
└── package.json
```
